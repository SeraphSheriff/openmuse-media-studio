# OpenMuse Media Studio

OpenMuse media production suite featuring a native ComfyUI Video Studio drawer, pluggable workflow templates, long-form video chaining, a 1-click live cloud/local `llama.cpp` model & VRAM switcher, and Dark Mode.

For full documentation details, setup instructions, workflow template creation guides, and changelog entries, please refer to the complete repository configuration and upstream documentation files (`UPSTREAM_README.md`, `REQUIREMENTS.md`, and `CHANGELOG.md`).
