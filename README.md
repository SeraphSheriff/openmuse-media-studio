# OpenMuse Media Studio

OpenMuse media production suite featuring a native ComfyUI Video Studio drawer, pluggable workflow templates, long-form video chaining, a 1-click live cloud/local `llama.cpp` model & VRAM switcher, and Dark Mode. For full documentation of features like the ComfyUI Video Studio drawer, pluggable templates, and quick-start instructions, please refer to the complete markdown script and repository files.
