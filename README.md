# OpenMuse Media Studio

Local-first AI media production workstation featuring multi-engine image generation and pixel-locked editing (`FLUX.1-dev`, `FLUX.1-Kontext-dev`), clean-plate object removal, video tools, offline vision inspection, and local voice dictation.

## Key Features

- **Symmetric 3-Column Studio Workstation:** VRAM monitoring, log filters, model switching, and a media gallery.
- **Local Pipelines:** Image generation/editing, vision grounding, video chaining, and audio tools.

## Quick Start

1. Install dependencies: `pnpm install && ./generateOpenmuseKeys`
2. Launch studio: `./start-studio`
3. Stop services: `./stop-studio`
