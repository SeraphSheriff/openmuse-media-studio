# OpenMuse Media Studio

**OpenMuse Media Studio** is a local-first AI media production workstation featuring a 3-column studio UI, live model and VRAM management, local image/video/vision/voice pipelines (including `Qwen3-TTS` zero-shot voice cloning and `LTX-2.3` video chaining), and an interactive **Help & Prompts** guide. For full feature details and documentation, refer to the repository files.
